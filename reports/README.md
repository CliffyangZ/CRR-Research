# Reports：結果、圖表與研究證據

這裡保存資料品質報告、實驗指標、模型輸出、圖表與錯誤分析，讓結論可以追溯至
資料、程式與執行設定。實驗流程位於 [`research/`](../research/README.md)，
共用實作位於 [`src/`](../src/README.md)。

## 輸出位置

目前只有本說明文件。以下為後續建議的結果分類，不表示已有實驗成果：

```text
reports/
├── README.md
├── data/<run-id>/          # 品質、去重、切分與標註檢查結果
├── models/<run-id>/        # 推論輸出、訓練紀錄與模型比較
└── evaluation/<run-id>/    # 指標、圖表、失敗案例與分析摘要
```

`run-id` 必須唯一，可用 `20261007-sam-baseline-001` 等名稱。
預訓練權重建議存於根目錄 `models/`；執行產生的 checkpoint 可隨模型 run 保存，
並在實驗紀錄中列出實際位置及識別碼。大量檔案不納入一般程式碼提交。
現有推論入口的輸出格式以 [`src/README.md`](../src/README.md) 與程式為準。

## 每次實驗紀錄

每個 run 建議附一份 `README.md`，至少填寫以下內容：

```markdown
# 實驗名稱

## 研究問題
假設、baseline，以及這次改變的變因。

## 資料與標註
資料版本或 manifest、來源、審閱狀態、切分方法、子集數量、排除條件。

## 執行設定
執行日期與時區、完整命令、程式版本（含未提交變更狀態）、環境、種子、
超參數、權重來源與識別碼、實際輸出位置。

## 評估結果
指標定義、評估子集與樣本數、baseline 與本次結果、圖表連結。
未評估的項目明確寫「未量測」，不填入推測值。

## 錯誤分析與限制
失敗案例、資料品質、潛在洩漏、缺失標註與重現條件。

## 結論與下一步
哪些結果支持或不支持假設，以及後續實驗。
```

表格或結構化結果必須標示指標名稱、單位、評估範圍與樣本數；圖表必須有
軸標籤、單位與資料來源。只比較使用相同資料切分與評估規則的結果。
指標不適用或無法計算時，寫明原因，不用零值代表缺失。

## 偽標註與人工校正

SAM／YOLO＋SAM 輸出的 `coco_annotations.json` 與 CVAT ZIP 是偽標註。
`metadata.json` 保存模型分數與審閱資訊；模型分數不是相對人工標註的實測準確度。
保存原始偽標註，將專家校正結果另存並記錄版本、審閱狀態與對應來源。
人工確認後的資料集應交由資料流程管理，報告保留其識別碼與位置。

## 保存與分享

原始資料不得由報告流程覆寫；每次執行使用獨立目錄，保留失敗紀錄。
影像、檔名與 metadata 分享前必須排除可識別病人的資訊。
目前 `.gitignore` 忽略 `reports/` 的產物，僅例外保留本 `README.md`；
因此本機結果仍需另行備份，不能把未入版控的檔案當作其他人必定能取得的證據。
研究結論必須附資料與產物取得方式，或明確說明存取限制。
