## Clarifications

### Session 2026-10-12

- Q: U-Net baseline 要分割哪些類別？ → A: 牙齒／背景二元語意分割；tooth 聯集為前景，Metal 不獨立預測，重疊處保留 tooth。

- Q: data/seg_dataset/ 的 tooth 標註目前屬於哪種審閱狀態？ → A: 全部為人工標註，且經專家確認，可作人工參考標準。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 取得可信且對齊的分割資料 (Priority: P1)

研究人員能從指定資料集取得可追溯的牙齒遮罩，確認既有切分與增強不會破壞標註或造成資料洩漏。

**Why this priority**: 分割目標及影像遮罩對齊是可信 baseline 的基礎。

**Independent Test**: 使用正常、多牙、邊緣截斷及錯誤多邊形樣本，核對資料清單、遮罩疊圖與處理紀錄。

**Acceptance Scenarios**:

1. **Given** 指定資料集及既有三個子集，**When** 盤點，**Then** 每張影像具有標註配對、類別、來源、審閱狀態與納入或排除原因，並產出病人／近重複跨子集檢查結果。
2. **Given** 同圖多顆 tooth 標註及 Metal 標註，**When** 建立目標遮罩，**Then** tooth 多邊形聯集為前景，其餘為背景；Metal 不建立獨立類別，也不覆蓋既有 tooth 前景。
3. **Given** 訓練影像與遮罩，**When** 執行允許的幾何增強，**Then** 兩者同步轉換、標籤維持離散值；若任一有效牙齒可見區域被額外截斷，取消整次幾何變換並保留亮度／對比增強。
4. **Given** 驗證或測試資料，**When** 處理，**Then** 僅執行固定前處理與尺寸處理，無隨機增強。

---

### User Story 2 - 完成可追溯的基準訓練 (Priority: P2)

研究人員能設定並完成一次 U-Net baseline 訓練，保留選定權重、學習紀錄及重跑所需資訊。

**Why this priority**: 建立後續分割實驗可比較的起點。

**Independent Test**: 以小樣本完成資料讀取、訓練、驗證與權重載入，再核對正式執行紀錄的完整性。

**Acceptance Scenarios**:

1. **Given** 通過資料檢查的版本，**When** 啟動實驗，**Then** 可指定資料與輸出位置、種子及訓練設定，執行有唯一識別碼。
2. **Given** 訓練完成，**When** 選擇權重，**Then** 依預先登錄的驗證集規則選模，保存最佳與最後權重及選擇依據，測試集不參與選擇。
3. **Given** 資源不足或訓練中斷，**When** 執行停止，**Then** 保留設定、已產生紀錄與失敗原因，不標示為成功。

---

### User Story 3 - 檢視固定測試集表現 (Priority: P3)

研究人員能取得分割指標、原圖對齊預測與錯誤案例，判斷下一步改善方向。

**Why this priority**: baseline 的價值在於可查證的表現及限制。

**Independent Test**: 使用已知遮罩配對核對指標，並以已保存權重對固定測試集產出報告。

**Acceptance Scenarios**:

1. **Given** 固定權重與測試清單，**When** 評估，**Then** 產出牙齒 Dice、IoU、precision、recall、樣本數及指標定義，沒有有效結果時附原因。
2. **Given** 預測遮罩，**When** 檢視案例，**Then** 可在原圖座標比較標註與預測，查看漏分、誤分及邊界偏差。
3. **Given** 單次實驗結果，**When** 撰寫結論，**Then** 明列標註審閱狀態、洩漏限制及未量測的種子變異，提供至少一項有案例支持的改善建議。

### Edge Cases

- 損毀影像、缺失配對、未知類別、空／退化／越界多邊形：隔離並記錄原因；缺失標註不得自動視為背景樣本。
- 經確認的無牙齒影像可作背景樣本；空標註但未確認者須先審閱。
- 原圖已有截斷牙齒保留可見標註；增強不可新增截斷，不得刪除牙齒以接受變換。
- 同圖多牙或多個多邊形以聯集表示，不要求分開相接牙齒或識別牙位。
- 病人資料不足或既有切分含近重複：揭露缺項；確認洩漏時修正並凍結新清單後才能正式訓練。後續新增標註若未確認審閱狀態，須另行標示，不沿用目前版本的人工確認身分。
- 全背景標註／預測與零分母依已登錄規則報告，不以任意零值掩蓋未定義結果。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: MUST 使用 `data/seg_dataset/` 作預設資料來源，盤點 train、val、test 的影像與 COCO 多邊形標註；逐檔檢查可解碼性、位元深度、通道、尺寸、標註配對與合法性，保存資料版本及排除原因。目前資料版本的 tooth 標註已由使用者確認全部為人工標註且經專家確認，MUST 記錄此確認來源與適用版本；Metal 的來源與審閱狀態另行記錄，不由 tooth 狀態推定。
- **FR-002**: baseline MUST 產出牙齒／背景二元語意分割；同圖所有 tooth 多邊形取聯集。Metal 不作獨立目標，僅有 Metal 且無 tooth 覆蓋的像素視為背景，與 tooth 重疊者保留 tooth 前景；此類別範圍已由使用者確認。
- **FR-003**: MUST 優先查核既有切分，採病人及近重複分組防洩漏；不得為湊比例拆開同組。修正切分須保存理由、新舊清單及種子，正式調參前固定測試集。病人資訊缺失時記錄替代分群及殘餘風險。
- **FR-004**: MUST 沿用 spec1 的 NLM → CLAHE → USM 固定影像前處理，再執行僅訓練集適用的增強；固定處理不得改動遮罩。已確認 8-bit 影像採固定線性強度映射，不做逐張 min–max；其他位元深度須先檢查。全部參數及尺寸處理完整次序於訓練前登錄。
- **FR-005**: MUST 沿用 spec1 保守增強，僅允許小幅亮度／對比、旋轉、平移；禁止隨機縮放、翻轉、Mosaic、MixUp、隨機裁切與彈性變形，包括預設增強。幅度、機率與組合順序於規劃登錄；強度增強僅作用於影像，幾何變換同步作用於影像及全部牙齒遮罩。任一有效牙齒可見區域新增截斷時取消整次幾何變換，保留亮度／對比，不刪標註接受變換。
- **FR-006**: 尺寸統一 MUST 使用固定等比例縮放及補邊，保留完整內容；遮罩縮放不得產生新類別值，補邊為背景。MUST 記錄原尺寸、縮放及補邊，將預測還原至原圖；驗證、測試與推論沿用相同固定規則，不作隨機增強。
- **FR-007**: MUST 以 U-Net 建立單一 baseline，依使用者要求將神經網路架構置於 `research/models/`；實驗編排置於 research，共用資料處理／訓練／評估邏輯置於 src，結果證據置於 reports。架構變體、初始化及權重來源於規劃登錄。
- **FR-008**: MUST 提供可配置資料、輸出、種子及訓練設定的執行方式，涵蓋資料檢查、小樣本驗證、正式訓練、驗證選模及固定測試評估。MUST 至少完成一次正式 baseline 訓練並保存最佳及最後權重、各輪訓練／驗證損失及驗證指標。
- **FR-009**: MUST 在正式訓練前登錄停止條件與選模規則；預設按驗證集牙齒 Dice 最高選模，同值選較早輪次。二元預測預設閾值為 0.5；若調整，只能用驗證集決定且測試前固定。
- **FR-010**: 每次執行 MUST 保存唯一識別碼、實際命令、程式版本及未提交變更、環境及裝置、種子、超參數、資料／標註版本、切分、前處理／增強設定、初始化、權重識別及產物位置；失敗執行保留原因，不覆寫既有結果。
- **FR-011**: MUST 在原圖座標計算前景牙齒 Dice 為主指標、IoU／precision／recall 為輔助，主要彙總為全部有效評估像素累計計算，另列逐圖平均與逐圖結果；補邊不納入評估。零分母、空遮罩及排除規則須在評估前固定，並報告影像數、有效像素數及標註審閱狀態。
- **FR-012**: MUST 產出漏分、誤分及邊界偏差案例與原圖疊圖、限制及改善建議。驗收以流程、權重及可查證報告完整為準，不設最低準確度；單種子結果標示探索性，不宣稱已量測穩健性或臨床能力。

### Key Entities *(include if feature involves data)*

- **資料與標註版本**: 影像、多邊形類別、來源、審閱狀態與有效性。
- **切分清單**: 子集、病人或替代分組、重複檢查及修訂紀錄。
- **分割樣本**: 原影像、牙齒遮罩及尺寸／增強轉換紀錄。
- **實驗執行**: 唯一識別碼、設定、環境、狀態、學習紀錄及權重。
- **評估報告**: 指標定義、評估母體、逐圖結果、疊圖、限制與證據連結。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% 納入影像可追溯來源、標註及子集，100% 排除項有原因；已知同病人／近重複組跨子集數為零，資訊不足者明示限制。
- **SC-002**: 對齊驗證涵蓋多牙、Metal 重疊、無牙齒、不同長寬比、合法變換、新增截斷及原圖截斷七類案例，全部符合既定遮罩與增強規則；遮罩標籤無新增值，尺寸轉換的控制點還原誤差每軸不超過 1 個原圖像素。
- **SC-003**: 至少一個正式實驗完成訓練、選模及固定測試評估；100% 正式執行具備 FR-010 重現資訊，成功執行保存最佳與最後權重。
- **SC-004**: 固定測試集有四項分割指標與逐圖結果，每項為有效數值或明確的未定義原因；100% 結果標示評估母體、樣本數、標註審閱狀態與彙總規則。
- **SC-005**: 研究人員能從報告追溯設定、資料切分及權重，檢視三類錯誤各至少一個實際案例（未發生者標示零例），並取得至少一項有證據支持的後續實驗建議。

## Assumptions

- 本次命令只建立規格，不執行訓練。範圍包含一個 U-Net baseline；多模型比較、多種子、消融實驗、instance segmentation、牙位辨識、Metal 獨立分割、landmark、CRR 及部署均不納入。
- 使用者已確認採 tooth 二元語意分割，保留原始 Metal 標註作追溯。
- 2026-10-12 初步盤點：train 61 張／139 筆標註、val 20 張／48 筆、test 20 張／47 筆；標註總數包含 tooth 與 Metal，尚未代表全部通過檔案及幾何品質檢查；tooth 的人工標註與專家確認狀態已由使用者確認。
- 依賴 [spec1](../001-train-tooth-detection/spec.md) FR-003／FR-005 的前處理及增強政策；偵測框規則改為遮罩同步與有效牙齒區域不新增截斷，不沿用偵測模型或 AP 指標。
- `research/models/` 目前為空目錄；架構位置為使用者指定限制，其餘可重用邏輯遵循憲章分工。尺寸、資源、訓練輪數、損失、最佳化設定及增強數值留待規劃。
- 資料來源授權與病人資訊尚待盤點；目前 tooth 標註全部為人工標註且經專家確認，此資訊來自使用者於 2026-10-12 的確認，並非由 COCO 格式推定。Metal 審閱狀態及後續新增資料須另行記錄。

## Research Integrity *(mandatory for data/model features)*

原始影像與標註保持不變，衍生遮罩保留原多邊形來源與轉換設定。目前指定資料版本的 tooth 標註全部為人工標註且經專家確認，以其作為牙齒分割的人工參考標準；報告記錄使用者確認來源、日期及資料／標註版本。Metal 狀態不由此推定。後續新增資料仍須分別記錄人工、偽標註及專家校正狀態；未確認標註另行評估，不能併入人工確認子集宣稱準確度。

病人與近重複組不得跨子集，缺少病人資訊不得宣稱已排除病人層級洩漏。既有目錄分割不視為已通過洩漏檢查；測試集不得用於前處理擬合、調參、閾值或權重選擇。若已使用測試結果修改設定，須記錄並以新的未使用評估資料支持確認性結論。

以 TP、FP、FN 分別表示牙齒像素正確預測、背景誤判為牙齒及牙齒漏分；Dice = 2TP/(2TP+FP+FN)，IoU = TP/(TP+FP+FN)，precision = TP/(TP+FP)，recall = TP/(TP+FN)，單位均為 0–1。零分母結果標記未定義；逐圖平均排除該指標未定義的影像並列有效數量，另報全背景影像數及其誤分像素數。主指標由全體有效影像的像素計數彙總，不與逐圖平均混用。

報告列出評估子集、樣本量、有效像素、排除條件、標註版本、閾值及實驗／權重識別碼。公開產物不含可識別病人的資訊。單次基準不代表穩健性或臨床診斷效能，未執行的量測明示未量測。
