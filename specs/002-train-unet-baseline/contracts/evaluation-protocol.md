# Contract: 評估協議

- **母體**：固定 test 清單中 `status=included` 的影像；排除項與原因列於報告。
- **座標**：機率圖去補邊 → bilinear 還原至原圖尺寸 → 閾值 0.5 → 與原圖解析度 tooth 聯集遮罩比較；補邊像素不計。
- **定義**（像素，0–1）：Dice = 2TP/(2TP+FP+FN)；IoU = TP/(TP+FP+FN)；precision = TP/(TP+FP)；recall = TP/(TP+FN)。
- **主要彙總**：全體有效影像的 TP/FP/FN 累計後計算（Dice 為主指標）。
- **逐圖平均**：另列；排除該指標分母為 0 的影像並報告 `n_valid`；不與累計混用。
- **零分母**：標記 `undefined` 與原因（`gt_empty_and_pred_empty` 等），不以 0 或 1 取代。全背景 GT 影像數與其 FP 像素數另列。
- **選模／閾值**：僅用 val；test 不得用於選模、閾值、前處理擬合；若曾用 test 調整，報告須標註並要求新資料確認。
- **報告必含**：子集、`n_images`、`n_valid_pixels`、排除條件、資料／標註版本、tooth 審閱狀態（人工＋專家確認，使用者 2026-10-12 確認）、Metal 狀態（未知）、閾值、`run_id`、權重 sha256、單種子探索性聲明、未量測項（種子變異、穩健性、臨床能力）。
- **錯誤案例**：漏分（FN 連通區 ≥ GT 前景 2%）、誤分（FP 連通區 ≥ 影像面積 0.1%）、邊界偏差（HD95）；每類至少列一例或標示零例；疊圖於原圖座標。
