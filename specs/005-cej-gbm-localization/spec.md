# Feature Specification: 三訊號 CEJ 雙側定位

**Feature Branch**: `main`（本次無分支 hook，未建立功能分支）

**Created**: 2026-10-13

**Status**: Draft

**Input**: 使用 width、gray、curvature 三種側別軸向訊號，結合既有牙冠／牙根方向與人工 CEJ 標註，以 GBM 回歸決定左右 CEJ 兩點；研究入口指定為 `notebooks/cej_FE.ipynb`，資料以專案 `data/` 為預設。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 檢視雙側 CEJ 訊號 (Priority: P1)

研究者選擇單顆牙，檢視牙冠到牙根方向、左右邊界與三種訊號，確認頸部候選位置可被辨識。

**Why this priority**: 訊號與方向是否正確，是定位與可信評估的前提。

**Independent Test**: 使用一顆具有影像、mask 與方向資訊的牙，獨立產生左右訊號及影像疊圖。

**Acceptance Scenarios**:

1. **Given** 有效牙齒資料，**When** 執行訊號分析，**Then** 每側每個有效軸向 bin 均具有三個有限且介於 0–1 的分數，無效 bin 明確標記。
2. **Given** 旋轉或牙冠朝向不同的牙齒，**When** 使用既有方向判定，**Then** 軸向始終由牙冠指向牙根，left 為 s<0、right 為 s>0，疊圖可核對側別。

---

### User Story 2 - 由人工標註學習並預測兩點 (Priority: P1)

研究者以人工標註建立定位模型，對未提供 CEJ 標註的有效牙齒取得左右各一個 CEJ 預測點。

**Why this priority**: 將候選訊號轉成可使用的雙側定位結果，是本功能核心價值。

**Independent Test**: 以有標註資料建立模型，將另一組牙齒的標註隱藏後執行定位，核對輸出座標及側別。

**Acceptance Scenarios**:

1. **Given** 有效人工標註及對應牙齒，**When** 準備訓練目標，**Then** 依牙軸座標重新判定側別，不直接將較小影像 x 座標視為 s<0。
2. **Given** 已建立的模型及有效未標註牙齒，**When** 預測，**Then** 輸出恰好兩個具有側別的有限座標，分別位於各側外邊界；不讀取該牙人工 CEJ 點作為輸入。
3. **Given** 一側無有效邊界，**When** 預測，**Then** 該側輸出不可定位狀態與原因，保留另一側結果，不捏造缺失點。

---

### User Story 3 - 核對定位品質與重現結果 (Priority: P2)

研究者檢視預測與人工點的差異、分組驗證結果及失敗案例，判斷學習定位是否優於固定規則定位。

**Why this priority**: 必須有獨立、可追溯的證據，才能判斷改進是否成立。

**Independent Test**: 對固定評估資料與既有預測結果產生誤差摘要、樣本清單及疊圖，不需重新訓練。

**Acceptance Scenarios**:

1. **Given** 固定的分組驗證切分，**When** 比較學習定位與基準方法，**Then** 兩者使用相同牙齒、側別、誤差單位及排除規則。
2. **Given** 一次執行完成或失敗，**When** 查閱結果，**Then** 可追溯資料版本、切分、設定及成功／失敗原因。

### Edge Cases

- mask 空白、破碎、影像缺失、ROI 尺寸或座標版本不符：拒絕該樣本並記錄原因。
- 平坦灰階、固定半寬、無凹向峰值：有效訊號回傳零分，不產生除零或非有限值。
- 軸向 bin 無邊界、s=0 或方向判定失敗：標記無效，不任意指派側別。
- 人工點缺失、超出 ROI、兩點落同側或接近牙軸而無法定側：列入待檢查清單，不靜默納入雙側監督。
- 人工點不完全落在 mask 邊界：保留原始人工座標供誤差評估，記錄其到邊界距離，不覆寫人工點。
- 多峰、兩側頸部高度不同：兩側分別定位；相同輸入與設定須有一致的候選選擇結果。
- 分組數不足：明確停止正式驗證並說明不足，不改成會洩漏的逐牙隨機切分。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 研究者 MUST 能從指定 notebook 依序完成資料檢查、訊號檢視、模型建立、推論與評估，且可配置資料及輸出位置。
- **FR-002**: 系統 MUST 沿用既有牙冠／牙根方向判定，定義 t 由牙冠至牙根、s 為垂直牙軸的有號位置，記錄正向規則及 ROI／原圖轉換資訊。
- **FR-003**: 系統 MUST 為 left（s<0）與 right（s>0）各軸向 bin 產生 width、gray、curvature 三種 0–1 分數，並分別記錄有效性；無效不得與有效零分混淆。
- **FR-004**: width MUST 表達半寬對 t 的二階變化之正部；gray MUST 表達沿邊界內側灰階經多尺度 Gaussian 導數取得的牙冠較白至牙根較暗下降量；curvature MUST 表達外輪廓多尺度平滑後 signed curvature 的頸部凹向峰值並對應回 t-bin。輪廓行走方向不得改變凹向的意義。
- **FR-005**: 系統 MUST 從人工訓練標註依牙齒識別碼關聯影像、mask、方向及座標資料；驗證版本、標註狀態、點數、數值與範圍，提供可用與排除樣本數及原因。
- **FR-006**: 系統 MUST 以三種訊號及其軸向／側別關係，使用使用者指定的 GBM 回歸產生左右定位；訓練目標須源自對應人工點，預測不得依賴待測牙齒的人工點。
- **FR-007**: 每個完整有效輸入 MUST 輸出 left、right 各一個對應外邊界的 CEJ 點，包含牙齒識別碼、ROI 像素座標、處理狀態；具備有效轉換資訊時亦輸出原圖像素座標，否則標示原圖座標不可用。
- **FR-008**: 系統 MUST 提供左右三種訊號曲線，以及包含牙軸、mask、預測點和可用人工點的疊圖，能依牙齒識別碼查閱。
- **FR-009**: 系統 MUST 只在訓練資料內進行分組驗證與模型選擇；同病人、來源影像及近重複影像不得跨組；缺病人識別時採來源影像與近重複群組並揭露限制。
- **FR-010**: 評估 MUST 提供 ROI 座標下左右點及合併的歐氏距離平均值、中位數、第 90 百分位與 5 像素內比例，並列出牙齒數、點數、完整雙點覆蓋率及排除／失敗數。
- **FR-011**: 系統 MUST 與不使用人工點的固定三訊號等權候選峰值基準比較；候選有效範圍、峰值同分規則及所有設定須在評估前固定並記錄。
- **FR-012**: 每次執行 MUST 保存唯一識別碼、資料與標註版本、程式版本及未提交變更狀態、環境、隨機種子、設定、分組清單、模型識別及輸出位置；保留失敗紀錄，無法完整追溯者標為探索性。

### Key Entities

- **牙齒樣本**：牙齒與來源影像識別碼、病人／替代分組、灰階影像、mask、ROI 轉換及牙冠／牙根方向。
- **側別訊號**：牙齒、側別、t-bin、三種分數、有效性與失敗原因。
- **人工 CEJ 標註**：資料版本、標註者與審閱狀態、ROI／原圖兩點及由牙軸重新確定的側別。
- **定位結果**：牙齒、模型／執行識別碼、左右座標、側別狀態及可追溯來源。
- **評估紀錄**：固定分組、基準與預測、每點誤差、覆蓋率、排除項目及彙總指標。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 所有有效 bin 的三種分數均為有限的 0–1 值，所有無效 bin 均可識別；平坦訊號案例沒有非有限結果。
- **SC-002**: 所有宣告完整成功的牙齒均具備兩個側別正確且位於各側外邊界的點；所有不完整輸入均有明確失敗／部分成功狀態。
- **SC-003**: 在固定分組的未參與該次學習樣本上，雙側合併平均定位誤差低於固定規則基準，且完整雙點覆蓋率不低於基準；此為研究驗收目標，未達標須如實呈現，不代表功能已證實有效。
- **SC-004**: 每次評估的樣本與點數、左右與合併誤差、5 像素內比例及排除原因均可追溯到逐牙紀錄；不同子集的分組重疊數為零。
- **SC-005**: 研究者可由單一牙齒識別碼查到訊號曲線、定位疊圖與誤差；相同資料、切分與設定重跑的逐點座標差異不超過 0.01 ROI 像素，若無法達成須揭露非確定性與觀測差異。

## Assumptions

- 使用者最後的「以 data/」視為預設資料根目錄要求，未推定額外資料篩選條件；路徑可配置。
- 訓練標註實際位於 `data/cej_annotations/cej_train_manual.json`，目前記錄 138 顆 annotated 牙齒；此為輸入盤點數，非保證全部可用。
- `notebooks/cej_FE.ipynb` 目前為空白研究入口；本次 specify 僅建立規格，實作留待後續階段。
- 既有牙冠／牙根演算法及對應 ROI、mask、轉換資訊可取得；若缺漏應明確阻擋該樣本。
- notebook 入口為使用者明確指定，複用邏輯與正式證據仍依憲章分工，具體組織由規劃階段決定。
- GBM、三種訊號定義及 notebook 路徑是使用者指定約束；不在規格中預先選擇套件、超參數或回歸目標編碼。
- 5 ROI 像素是便於比較的研究報表門檻，不代表臨床容許誤差；不預設毫米換算。
- 本功能不含重新訓練牙齒分割、改造牙冠／牙根演算法、人工標註介面、CRR 計算或臨床驗證。

## Research Integrity *(mandatory for data/model features)*

人工標註宣告為 researcher 人工標點，未宣稱專家確認。其座標以 x 向右、y 向下、256×256 ROI 像素記錄，原始兩點按影像 x 排序；訓練側別必須由牙軸重新映射。mask 若為模型產物，須保留偽標註來源與審閱狀態，不以人工 CEJ 標註推定 mask 已人工確認。

訓練與模型選擇僅使用訓練標註及其來源資料，以病人優先、來源影像與近重複群組為最低分組單位。已存在的 `data/cej_annotations/cej_roi_2a0c9441396f.json` 含 test 標註，本功能預設不將其納入訓練或調參；如後續進行最終測試，必須先凍結模型與設定並獨立報告。任何由資料擬合的轉換僅可由當次訓練分組取得。

主要誤差為預測點與同側原始人工點的 ROI 歐氏距離（像素），不是與投影後人工點的距離；左右分開與合併時說明點數權重。完整雙點覆蓋率分母為評估清單內全部牙齒，分子為兩側均成功定位的牙齒。距離統計使用有有效人工點與預測點的配對，另列缺失，不以排除失敗樣本隱藏覆蓋率下降。所有比較維持相同切分、樣本與單位，原始影像和人工標註不覆寫；尚未執行的訓練與指標一律標為未量測，研究結果不得表述為已驗證的臨床能力。
