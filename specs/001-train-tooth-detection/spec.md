# Feature Specification: 牙齒 Detection 模型訓練與實驗評估

**Feature Branch**: 沿用目前分支；本次未建立分支

**Created**: 2026-10-07

**Status**: Ready for planning — PA 單類別牙齒偵測三模型訓練比較

**Input**: User description: "訓練牙齒 Detection 模型；前處理採 NLM → CLAHE → USM，之後做保守 Data Augmentation（禁止隨機縮放、保留固定 letterbox），訓練 YOLO v8、v11、v26 並評估分析。"

## Clarifications

### Session 2026-10-07

- Q: 第一個 baseline 要採用哪種增強策略？ → A: 保守增強：小幅亮度／對比、旋轉與平移；禁止隨機縮放增強（2026-10-09 修訂）；關閉翻轉、Mosaic、MixUp、隨機裁切與彈性變形。
- Q: 旋轉或平移造成牙齒超出影像邊界時，如何處理？ → A: 若任何有效牙齒框被額外截斷，取消該次幾何變換，保留亮度／對比增強；原始影像已截斷的牙齒依既有標註規則保留。
- Q: 目前 PA 影像的來源格式是什麼？ → A: 已匯出的 PNG／JPEG，主要為 8-bit；實際位元深度、通道數與強度範圍仍須逐檔盤點。
- Q: 不同尺寸的 PA 影像，要如何統一輸入尺寸？ → A: 等比例縮放加補邊（letterbox），保留原始長寬比例與完整影像內容；目標解析度與補邊值於規劃階段設定。
- Q: baseline 要如何處理灰階強度與對比？ → A: 2026-10-09 修訂：採 NLM → CLAHE → USM 固定前處理，再以固定線性規則映射至模型輸入範圍；不做逐張 min–max，非 8-bit 檔案須另行檢查。

### Session 2026-10-09

- Q: 「不要做縮放」的範圍是？ → A: 禁止資料增強中的隨機縮放；保留固定 letterbox（等比例調整尺寸及補邊）輸入尺寸處理。
- Q: NLM、CLAHE、USM 要如何組合？ → A: 每張影像依序套用 NLM → CLAHE → USM，再做僅適用於訓練集的資料增強。
- Q: 除了禁止隨機縮放，其餘資料增強是否沿用原先的保守設定？ → A: 保留小幅亮度／對比、旋轉、平移；關閉隨機縮放、翻轉、Mosaic、MixUp、隨機裁切與彈性變形。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 建立可信的訓練資料 (Priority: P1)

研究人員能確認資料與標註品質，取得可追溯且避免資料洩漏的訓練、驗證與測試資料，以確保 baseline 評估有意義。

**Why this priority**: 資料與標註定義直接決定模型能學習及評估的目標。

**Independent Test**: 使用含正常、重複、損毀與錯誤標註的資料樣本，檢查資料清單、品質報告及分組切分結果。

**Acceptance Scenarios**:

1. **Given** 已指定資料來源與標註，**When** 完成資料檢查，**Then** 每筆資料都有來源、標註狀態及納入或排除原因。
2. **Given** 同病人或近重複影像，**When** 建立切分，**Then** 同組資料只存在於一個子集；缺少病人資訊時記錄替代分群與殘餘風險。
3. **Given** 影像或座標需轉換，**When** 前處理完成，**Then** 原始資料保持不變，影像與標註仍對齊，且可追溯處理設定。
4. **Given** 含邊緣牙齒的訓練影像，**When** 幾何增強使任一有效牙齒框超出邊界，**Then** 整次幾何變換取消，全部框回復原位置，已套用的亮度／對比增強保留；框均在界內時允許變換並同步更新座標。
5. **Given** 不同長寬比例且含邊緣牙齒的 PA 影像，**When** 完成 letterbox 前處理並將框還原至原圖，**Then** 全部原始影像內容保留、牙齒比例不變，且框座標還原誤差每個座標不超過 1 個原圖像素。

6. **Given** 有效的 8-bit 影像，**When** 完成固定前處理，**Then** 依序套用 NLM → CLAHE → USM，保存各階段設定，影像尺寸與框座標不因這三項強度處理改變；最終以固定線性規則映射至模型輸入範圍，不做逐張 min–max；非 8-bit 檔案進入檢查流程。

### User Story 2 - 選擇模型並完成可重現實驗 (Priority: P2)

研究人員能使用 YOLO v8、v11、v26 完成 PA 單類別牙齒偵測訓練，使用相同資料切分及評估規約比較，並保留足以重跑的紀錄。

**Why this priority**: 可重現的 baseline 提供後續改進與比較的起點。

**Independent Test**: 使用一份已確認的資料版本，檢查三個模型的來源紀錄與各自小樣本實驗的完整產物。

**Acceptance Scenarios**:

1. **Given** 資料範圍與資源限制已確認，**When** 登錄 YOLO v8、v11、v26 三個模型，**Then** 選擇紀錄記錄來源、授權條件、權重來源、任務適配性、資源需求與選擇理由。
2. **Given** 實驗設定已登錄，**When** 訓練成功或失敗，**Then** 均保留獨立執行識別碼、設定、狀態、紀錄與產物位置。
3. **Given** 各模型訓練完成，**When** 依預先登錄的規則選定權重，**Then** 僅以驗證集選模，保存權重並使用固定測試集產出初始評估。

### User Story 3 - 確定評估與分析結果 (Priority: P3)

研究人員能檢視整體與分組表現、錯誤案例及不確定性，提出有證據的模型選擇與後續實驗建議。

**Why this priority**: 結果需要揭露失敗情境，才能支持研究決策。

**Independent Test**: 使用固定的人工確認標註及預測結果，核對指標計算、錯誤分類與視覺化報告。

**Acceptance Scenarios**:

1. **Given** 固定預測與標註，**When** 評估模型，**Then** 指標定義、評估樣本、匹配規則、閾值、單位與排除條件均可查閱。
2. **Given** 有漏檢、誤檢、重複框或定位偏差，**When** 分析結果，**Then** 報告提供各類錯誤數量、代表案例及其對結論的影響。
3. **Given** 尚未量測或不支持的分組，**When** 撰寫結論，**Then** 明確標示未量測或樣本不足，不以信心分數替代實測表現。

### Edge Cases

- 損毀影像、缺失標註、越界或零面積框：隔離並記錄原因；未標註影像不得自動當作無牙齒影像。
- 無牙齒、缺牙、遮擋、影像邊緣截斷、修復物及低品質影像：依確認的標註規則納入或排除，分別記錄。
- 病人識別資訊不足或分組後某類別樣本過少：揭露風險與分布，不藉拆分同組資料湊足比例。
- 保守增強的幾何變換若使任何有效牙齒框被額外截斷：取消整次幾何變換（含旋轉與平移），回復幾何變換前的影像與框，保留亮度／對比增強；原始影像已截斷的牙齒依既有標註規則保留。
- 訓練中斷、資源不足或無有效預測：保留失敗原因；無法定義的指標須說明原因，不偽填零值。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 資料範圍 MUST 限定根尖片（PA）；來源為已匯出的 PNG／JPEG，主要為 8-bit；前處理 MUST 逐檔確認解碼結果、位元深度、通道數與強度範圍，不得將所有檔案直接假定為 8-bit 灰階；訓練前 MUST 完成來源、可用影像量、標註格式及病人分組資訊盤點，缺少資訊時記錄缺項與處理限制。
- **FR-002**: 偵測任務 MUST 對每顆牙輸出矩形框，所有牙齒使用單一 tooth 類別，不辨識牙位編號或牙齒種類。框以影像內可見牙體的最小軸向外接矩形為原則；截斷與遮擋牙齒只框可見部分，無法確認牙體者須標記待審閱，不當作確認標註。
- **FR-003**: 前處理 MUST 提供資料品質與分布摘要、重複檢查、標註驗證、排除清單、轉換紀錄及影像標註對齊檢查。 固定尺寸前處理 MUST 採等比例縮放加補邊（letterbox），不得以非等比例拉伸或中心裁切統一尺寸；全部標註框 MUST 同步縮放及平移。每張影像 MUST 保留原始尺寸、實際縮放比例、縮放後尺寸與各邊補邊量，以將預測框映射回原圖。訓練、驗證、測試及後續推論 MUST 使用相同的尺寸處理規則；目標尺寸、插值與補邊值於規劃階段設定並記錄。 固定前處理 MUST 依序套用 NLM（Non-Local Means，非局部均值去噪）→ CLAHE（Contrast Limited Adaptive Histogram Equalization，對比受限自適應直方圖均衡）→ USM（Unsharp Masking，反銳化遮罩銳化），且不改變影像尺寸或標註框座標。三項處理 MUST 一致套用於訓練、驗證、測試及後續推論，參數 MUST 在訓練前登錄，不得以測試集調整。確認為 8-bit 的影像在上述處理後 MUST 使用固定線性映射，將 0–255 映射至模型要求的輸入範圍，不做逐張 min–max。非 8-bit 或強度範圍異常的檔案 MUST 隔離檢查並記錄處理決定，不得直接套用 0–255 規則。資料增強 MUST 在 NLM → CLAHE → USM 完成後進行，僅用於訓練集；與 letterbox、輸入映射的完整次序及參數於規劃階段登錄，避免重複正規化。
- **FR-004**: 資料 MUST 優先以病人分組切分，同組近重複影像不得跨子集；比例與隨機種子必須記錄，測試集在調參前固定。
- **FR-005**: 從資料學得的處理參數 MUST 僅使用訓練集；隨機增強僅適用於訓練集，驗證與測試採固定且可重現的處理。 baseline MUST 採保守增強，僅允許小幅亮度／對比變化、旋轉與平移；隨機縮放增強 MUST 關閉，固定 letterbox 輸入尺寸處理仍保留；翻轉、Mosaic、MixUp、隨機裁切與彈性變形 MUST 關閉，包括訓練框架的預設增強。各方法的幅度、機率及組合順序 MUST 在訓練前登錄，並用影像與框疊圖檢查標註對齊；具體數值於規劃階段確定。 幾何變換 MUST 同步更新全部牙齒框；若變換後任一框超出影像邊界，MUST 取消該次幾何變換並回復變換前的影像與框，保留亮度／對比增強，不藉移除標註框接受該變換。原始影像中已截斷的牙齒 MUST 依 FR-002 保留。
- **FR-006**: MUST 訓練 YOLO v8、v11、v26 三個模型；每個版本 MUST 記錄正式來源、精確版本、模型規模、授權條件、初始權重來源、PA 單類別偵測適用性與資源需求。三者 MUST 使用相同資料版本、切分、固定前處理、資料增強政策與評估規約；框架差異及不可完全一致的設定 MUST 記錄。
- **FR-007**: 訓練流程 MUST 涵蓋資料檢查、小樣本驗證、訓練、驗證選模、固定測試評估及報告，各階段具有進入條件、產物與失敗紀錄。
- **FR-008**: 每次正式實驗 MUST 記錄實際命令、程式版本及未提交變更、環境、裝置、隨機種子、資料與標註版本、切分清單、權重識別、超參數、停止及選模規則與輸出位置。
- **FR-009**: 實驗 MUST 對 YOLO v8、v11、v26 各完成至少一次訓練，預先登錄設定與隨機種子；額外前處理對照實驗與多種子重複實驗列為後續工作。單次 baseline 結果 MUST 標示探索性，不宣稱已量測訓練隨機性或穩健性。
- **FR-010**: 評估 MUST 使用 AP@[IoU 0.50:0.05:0.95] 為主要指標，AP@0.50 為輔助指標；另報告 IoU 0.50 下的 precision、recall 與 F1。工作信心閾值以驗證集 F1 最大者選定，同值時採較高閾值，測試前固定。每個標註最多匹配一個預測，未匹配預測含重複框計為誤檢；AP 的插值、最大偵測數與零分母規則須在執行前登錄。評估須列明母體、影像數與牙齒標註數。
- **FR-011**: 本階段 MUST 以產出三個模型各自可重現的權重、固定測試集指標與錯誤分析及比較報告為驗收條件，不設最低效能門檻；效能數值作為後續實驗的參考起點。
- **FR-012**: 結果分析 MUST 包含整體與可用分組指標、樣本數、漏檢／誤檢／重複框／定位偏差、代表性成功與失敗案例、種子變異的量測狀態、限制及下一步建議；無支援資料的分組明示未量測。
- **FR-013**: 每項比較與結論 MUST 連結至實驗、資料版本、切分、模型權重及評估產物；公開報告不得包含可識別病人資料。

### Key Entities *(include if feature involves data)*

- **資料版本**: 影像來源、識別碼、分組資訊、品質狀態與納入／排除原因。
- **標註版本**: 框與類別、來源、偽標註身分、審閱狀態及標註規則。
- **切分清單**: 資料版本、分組規則、子集歸屬與洩漏檢查結果。
- **候選模型**: 正式來源、版本、授權、初始權重與選擇依據。
- **實驗執行**: 識別碼、假設、設定、環境、狀態、權重與產物。
- **評估報告**: 指標定義、結果、樣本數、錯誤案例、限制與結論證據。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% 納入資料可追溯至影像來源與標註版本；100% 排除資料有理由；切分清單中同組資料跨子集數量為零；增強驗證案例 MUST 覆蓋框均在界內、變換造成越界及原始牙齒截斷三種情境，全部符合 FR-005。
- **SC-002**: YOLO v8、v11、v26 各完成至少一次訓練；100% 正式執行具備 FR-008 的重現資訊，並保存選定權重與選模依據。
- **SC-003**: 三個模型分別在相同固定測試集產出 FR-010 所列的五項指標；每項皆有數值或無法計算的明確原因，且單次結果標示探索性，種子變異標示未量測。
- **SC-004**: 100% 報告指標具有定義、評估子集與樣本數；四類偵測錯誤均有計數，有發生者至少提供一例，未發生者註明零例。
- **SC-005**: 研究負責人可由報告追溯三個模型的設定、權重、切分及評估證據，確認訓練、評估與分析產物完整，並取得至少一項由錯誤分析支持的後續實驗建議。

## Assumptions

- 本次建立訓練與評估研究規格；本命令不執行模型訓練。
- Detection 確定為 PA 影像中每顆牙的單一 tooth 類別矩形框定位；分割、landmark、CRR 計算、臨床驗證與部署不納入本 feature。
- 使用者為研究人員與標註審閱者；依賴可合法使用的資料、相應標註及訓練資源。
- 評估指標採 FR-010 的 baseline 預設，尚未代表使用者指定效能門檻；本次要求 YOLO v8、v11、v26 三模型訓練比較，不要求額外前處理對照或多種子重複實驗。
- 影像來源已確認為主要 8-bit 的 PNG／JPEG；資料位置、數量、標註格式與病人識別資訊尚未提供，列為規劃階段盤點項目；若缺乏可用訓練標註或人工確認的評估標註，須先補足或標示無法完成相應階段。
- 模型家族確定為 YOLO v8、v11、v26；精確版本、模型規模、硬體、影像尺寸、切分比例與超參數於規劃階段依資料與資源登錄。

## Research Integrity *(mandatory for data/model features)*

原始影像不可覆寫，衍生資料保留來源與轉換設定。標註保留人工／偽標註來源及專家審閱狀態；未經人工確認的偽標註不視為人工 ground truth，不能據此宣稱對人工標註的準確率。

病人與近重複資料不得跨子集；缺少病人資訊時記錄替代分群與殘餘洩漏風險。測試集不得用於資料擬合、調參、閾值選擇或模型選擇。若測試後修改設定，須揭露已使用測試資料並取得新的未使用評估資料後才能做確認性結論。

AP 指定位與分類在指定重疊規則下的整體表現；precision 指預測中正確匹配的比例，recall 指標註中成功檢出的比例，F1 為兩者的調和平均。比例統一標示 0–1 或百分比，框重疊使用 IoU（交集面積除以聯集面積）。具體匹配、彙總、缺失類別與零分母處理在評估規約中固定。
