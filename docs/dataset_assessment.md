# 牙齒分割數據集評估報告

**生成日期**: 2026-10-12  
**評估範圍**: 兩個實驗數據集的統計與品質分析

---

## 概述

本報告評估兩個數據集，分別用於不同階段的牙齒分割研究：
1. **整張圖像分割** (`dv-20261009-01`) - spec 002 基線訓練
2. **單顆牙 ROI 分割** (`roi_2a0c9441396f`) - spec 003、004 實驗用

---

## 1. 整張圖像分割數據集 (`dv-20261009-01`)

### 1.1 基本資訊

| 項目 | 值 |
|---|---|
| **資料版本** | dv-20261009-01 |
| **用途** | Spec 002 baseline U-Net 訓練 |
| **影像總數** | 6 張（清單於 `manifests/` 目錄） |
| **標註類型** | COCO 格式多邊形 |
| **儲存位置** | `data/derived/dv-20261009-01/` |

### 1.2 目錄結構

```
dv-20261009-01/
├── images/         # 原始影像
├── labels/         # COCO 標註（polygons）
├── proposals/      # YOLO 偵測框
└── manifests/      # 每影像的前處理設定記錄
```

### 1.3 前處理規格（固定）

根據 `manifests/` 中的記錄：
- **NLM 去噪**: 已應用
- **CLAHE 直方圖均衡**: clip_limit=2.0, tile_grid=[8,8]
- **USM 銳化**: 可選
- **輸入對映**: 線性 uint8 (÷255 → float32)
- **Letterbox**: 等比例調整 + 邊界填充（背景灰 114）

### 1.4 標註品質

- **多邊形標註**: 人工確認（spec 002 需求）
- **偵測框來源**: YOLO v8（審閱狀態未知）
- **金屬（牙套）標記**: 獨立類別（在分割時視為背景）

### 1.5 數據洩漏控制

- **切分方式**: 既有（spec 001 中已凍結）
- **近重複檢測**: pHash hamming ≤ 6（防止同圖多版本跨子集）
- **病人層級洩漏**: 🟡 **風險**：無病人 ID，切分以圖像內容相似度分群

### 1.6 限制

- ⚠️ **樣本極少** (6 張) → baseline 訓練結果高度依賴初始化與種子
- ⚠️ **無外部驗證集** → 泛化能力未知
- ⚠️ **單一影像來源** → 可能存在拍攝條件、牙齒類型或患者差異未涵蓋

## 2. 單顆牙 ROI 分割數據集 (`roi_2a0c9441396f`)

### 2.1 基本資訊

| 項目 | 值 |
|---|---|
| **資料版本** | roi_2a0c9441396f |
| **來源資料集** | dv-20261009-01（6 張整圖） |
| **用途** | Spec 003 ROI 構建、spec 004 架構比較 |
| **總 ROI 數** | 232 個單顆牙 ROI |
| **標註類型** | 二元分割遮罩（牙齒 vs 背景） |
| **解析度** | 256×256 px (letterbox) |
| **原始解析度** | 各 ROI 的源圖座標 |

### 2.2 數據分割

| 子集 | ROI 數 | 占比 | 用途 |
|---|---|---|---|
| **train** | 138 | 59.5% | 權重更新 + 增強 |
| **val** | 48 | 20.7% | 模型選擇（驗證 Dice） |
| **test** | 46 | 19.8% | **一次性評估**（凍結後） |

**樣本量**: test 約 20 張源圖 → 同圖 ROI 非獨立

### 2.3 構建流程（Spec 003）

```
偵測框（YOLO） + 多邊形標註（COCO）
        ↓
  一對一配對 (IoU ≥ 0.5)
        ↓
  框外擴 10% + 等比 letterbox
        ↓
  CLAHE 固定參數前處理
        ↓
  單牙遮罩（鄰牙 = 背景）
        ↓
  凍結切分（pHash 分群）
```

### 2.4 ROI 特徵統計

#### 2.4.1 完整性

| 特徵 | 數量 | 占比 | 影響 |
|---|---|---|---|
| **正常 ROI** | 51 | 22.0% | 清晰的單顆牙 |
| **含鄰牙** | 178 | 76.7% | 鄰牙在 frame 內；已標為背景 |
| **被截斷** | 3 | 1.3% | 目標牙在邊界外；遮罩不完整 |
| **超出圖像** | - | - | 已在前處理補邊 |

#### 2.4.2 遮罩面積

| 統計量 | 值 | 備註 |
|---|---|---|
| **最小** | 4,780 px | 小牙（如門牙） |
| **平均** | 12,430 px | 256² = 65,536 px frame |
| **最大** | 24,274 px | 大臼牙 |

→ 變異大，可能影響小牙的邊界偵測

#### 2.4.3 子集間分佈

同一源圖的 ROI 都在同一子集（pHash 分群 + 群內隨機切分）

```
train (138 ROI): 86 來自約 40 張圖像
val   (48 ROI):  26 來自約 13 張圖像
test  (46 ROI):  26 來自約 20 張圖像
```

### 2.5 標註審閱狀態

| 類型 | 狀態 | 來源 |
|---|---|---|
| **多邊形** | ✅ 人工專家確認 | 使用者確認（2026-10-12） |
| **偵測框** | ❓ 未知 | YOLO v8（未人工驗證） |
| **金屬標記** | ❓ 未知 | 檔案標籤（部分缺失） |

**隱含假設**: 多邊形是真值；偵測框是代理（精度未驗證）

### 2.6 已知風險與限制

#### 2.6.1 數據品質風險

| 風險 | 等級 | 說明 |
|---|---|---|
| **病人層級洩漏** | 🔴 中 | 無病人 ID；pHash 分群可能不完美 |
| **偵測框精度** | 🟡 中 | 未人工驗證；可能包含邊界誤差 |
| **金屬/充填標記** | 🟡 中 | 部分缺失；但已篩選出 Metal 類別 |
| **小樣本** | 🔴 高 | test 46 ROI（約 20 圖）；種子變異大 |

#### 2.6.2 分割難點（error_cases）

在 spec 002/003/004 實驗中已統計：
- **牙根漏分** (10 ROI 代表例): 漏分占 GT 11–15%
- **鄰牙干擾** (35 ROI): 多存在鄰牙背景混雜
- **邊界截斷** (2 ROI): ROI 展開超出源圖

#### 2.6.3 未量測項

❌ **外部驗證**: 未在其他牙科影像資料集驗證  
❌ **掃描儀差異**: 所有圖像來自單一設備/設定  
❌ **牙位/上下顎**: 無此資訊，無法定位牙根側  
❌ **多類別分割**: 僅二元（牙齒 vs 背景）

## 4. 建議與後續步驟

### 4.1 數據品質改進

1. **人工驗證偵測框** (spec 003/004 升級)
   - 抽樣 10–20% 的框檢查 IoU、遺漏、誤判
   - 根據結果重新篩選或調整配對門檻

2. **補充牙位標註** (spec 004+ 可選)
   - 若 CRR 實驗啟動，標註牙位與上下顎
   - 精準定位牙根側，改進「牙根漏分」識別

3. **多掃描儀驗證** (泛化測試，scope 外)
   - 收集其他掃描儀/設定的牙科影像
   - 評估模型泛化能力

### 4.2 實驗設計改進

| 階段 | 改進項 |
|---|---|
| **Baseline (spec 002)** | 增加訓練影像至 20+ 張；多種子訓練（3–5） |
| **ROI 構建 (spec 003)** | 人工驗證框；檢查邊界截斷與鄰牙標記 |
| **架構比較 (spec 004)** | ✅ 已完成；3 種子、凍結協議、一次性 test |
| **後續 (spec 005+)** | 等容量變體；預訓練模型；多資料集驗證 |
